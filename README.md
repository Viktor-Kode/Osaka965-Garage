# Osaka965 Garage - Kuwait's Premier Auto Workshop

A modern, premium website for Osaka965 Garage, Kuwait's leading automotive service provider. Built with HTML5, CSS3, and vanilla JavaScript.

## Features

- **Responsive Design** - Mobile-first approach with seamless experience across all devices
- **Service Showcase** - Three main service categories with detailed descriptions:
  - Auto Repair & Servicing
  - Engine Tuning
  - Car Modification
- **Customer Reviews** - Integrated Google Reviews (4.2★ rating)
- **Appointment Booking** - Contact form for service appointments
- **Smooth Navigation** - Fixed navbar with smooth scroll behavior
- **Mobile Menu** - Full-featured mobile drawer navigation
- **Performance Optimized** - Lazy loading, backdrop filters, and scroll animations

## Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, grid, flexbox, animations
- **JavaScript (Vanilla)** - No frameworks required

## Sections

1. **Navigation** - Fixed navbar with logo, links, and CTA
2. **Hero** - Full-screen hero section with key stats
3. **Services** - Three service cards with details
4. **Why Osaka965** - Visual showcase with ratings
5. **Reviews** - Customer testimonials
6. **Booking** - Appointment form
7. **Footer** - Contact info and links

## Font Stack

- **Display**: Bebas Neue
- **Body**: DM Sans
- **Japanese**: Noto Sans JP

## Color Scheme

- Primary: Black (#0a0a0a)
- Accent: Gold (#c9a84c)
- Secondary: Dark grays with red accent
